# Ferns and Petals – Sales Analysis

## 1. Project Overview
This project focuses on analyzing sales performance for Ferns and Petals using Microsoft Excel.

The goal is to extract meaningful business insights from sales data and present them through an interactive dashboard.

## 2. Business Objectives
- Analyze overall sales performance.
- Identify monthly revenue trends.
- Determine the highest revenue-generating occasions.
- Identify top-performing products.
- Analyze sales distribution across cities.
- Evaluate average delivery time.

## 3. Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Slicers and Timeline

## 4. Dataset Description
The workbook contains five worksheets:

- Customers
- Orders
- Products
- Pivot Tables
- Dashboard

## 5. Key Performance Indicators (KPIs)
- Total Revenue: 3,520,984 INR
- Total Orders: 1,000
- Average Revenue per Order: 3,520.984 INR
- Average Delivery Time: 5.53

## 6. Key Insights
- March recorded the highest monthly revenue.
- Anniversary generated the highest revenue among occasions.
- Raksha Bandhan ranked second in revenue.
- The correlation between order quantity and delivery time is approximately zero.
- Sales performance varies across months, occasions, cities, and products.

## 7. Business Recommendations
- Investigate the factors behind peak monthly sales.
- Improve marketing strategies for lower-revenue occasions.
- Focus on top-performing products.
- Use city-level order trends to improve sales planning.
- Monitor delivery performance to identify operational improvements.
